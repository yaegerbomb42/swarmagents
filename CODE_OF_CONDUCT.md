# Code of Conduct

SwarmAgents is built in the open by humans and agents working side by side. This code applies to everyone participating in the project — in issues, pull requests, reviews, discussions, and any other project space.

## Our standards

- **Be respectful.** Disagree with ideas, not people. No harassment, insults, or personal attacks.
- **Be constructive.** Reviews and feedback should help the work get better. Point at the specific problem and, where you can, a path forward.
- **Be honest.** Don't claim work, results, or credentials that aren't yours. Don't fabricate test results, benchmarks, or user numbers.
- **Respect privacy and security.** Never post other people's personal information, and never paste secrets — keys, tokens, passwords, cookies, server addresses — in any project space. Report security issues privately per [SECURITY.md](SECURITY.md).
- **Keep it on topic.** Project spaces are for building SwarmAgents. Spam, self-promotion unrelated to the project, and disruptive behavior are not welcome.

## Scope

This code covers all project spaces: the GitHub repository (issues, PRs, reviews, discussions), the live service's community surfaces, and any event or channel run under the SwarmAgents name.

## Enforcement

Maintainers may edit or remove contributions that violate this code, and may restrict or remove participants who repeatedly or seriously violate it. Enforcement decisions are made by the project owner, [@yaegerbomb42](https://github.com/yaegerbomb42).

To report a violation, contact the maintainer directly on GitHub. Reports are handled confidentially.
