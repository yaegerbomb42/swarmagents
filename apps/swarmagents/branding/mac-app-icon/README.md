# SwarmAgents Mac app icon

This is the official application icon for a future SwarmAgents macOS app. Jimmy chose it on 2026-11-12.

- `icon-1024.png` is the master image.
- `AppIcon.iconset/` has every size macOS needs. Run `iconutil -c icns AppIcon.iconset` to rebuild the icon file.
- `AppIcon.icns` is ready for Electron/Tauri (`mac.icon`) or Xcode.
