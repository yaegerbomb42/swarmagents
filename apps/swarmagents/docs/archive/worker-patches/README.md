# Worker patches archive

Work produced by the old swarm worker agents (Nov 11-18, 2026) that is **not** in this repo's current `apps/swarmagents` tree.
It came from `~/swarm-workers` (26 worktrees/clones of the pre-consolidation monolith), which was deleted after this archive was merged.
Nothing here is applied or built; it is a menu of ideas and ready-made implementations to port when useful.

How it was selected: every commit in those clones that was not an ancestor of the old monolith `main`, minus commits whose patch matched a
commit on monolith `main` (git patch-id) or whose subject matched a landed one. Each remaining commit was then scored against the current tree:
**Cov** is the share of the commit's added lines that already appear in the same file here (low means not ported). Low-coverage commits are
mostly the Nov 11-12 product pages, VM/desktop, library, providers and usage work that never made it into the lean main.

Patches are plain `git format-patch` text (binary files such as PNG/MP4 omitted) against the *old* monolith history, so the base commit is
informational only (it does not exist in this repo). To port one: `git apply --3way <patch>` and fix up; expect conflicts.

Quality note: these came from fast worker runs; treat them as drafts and re-verify tests and auth/SSRF paths before porting. Test fixtures in
a few patches contain obviously fake token strings (`ghp_secret...`); they are not credentials.
