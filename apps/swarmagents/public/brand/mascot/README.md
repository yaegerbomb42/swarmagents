# Mascot sprite sheet

mascot-sheet.png is 1536x1224 with a transparent background. It is an 8x8 grid of 192x153 frames, read left to right, top to bottom, at about 160ms per frame (64 frames total).
- Row 1 to the first 3 frames of row 2 are a wave (hello).
- The rest of row 2 is idle.
- Row 3 is a lean with an alert mark (attention or notification).
- Rows 4 to 8 are thinking and fidgeting (working).

mascot.gif is the full 64-frame loop at 192x153.
